# J-analyzer-majang
## これ何
じゃんたまのプレイ画像の解析をして、何切るのプログラムに投げるための情報を取得する

## Input
Gyazoのじゃんたまプレイ中のスクショ画像URL

## Output
https://github.com/nekobean/mahjong-cpp
に返すための情報

- [x] 手牌の中身(赤ドラ含め)
- [x] 場風
- [x] 自風
- [x] 順目(自風と余牌から計算)
- [x] ドラ
- [ ] 複数のドラ表示

- [ ] ドラのマッチング精度を上げるためのテンプレート切り取り生成
- [x] 牌譜詳細からの画像への対応(別途対応させなくても、できてそう？)
- [ ] 鳴いた手牌への対応
